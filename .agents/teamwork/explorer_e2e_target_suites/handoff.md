## 2. Logic Chain

1. **Test Runner Health & Discovery**:
   - Because `.venv\Scripts\python.exe -m pytest --collect-only` cleanly discovers 899 tests in 0.46s without errors, the virtual environment, PyQt6, numpy, and pytest configurations are fully functional.
   - Because `tests/e2e/conftest.py` is located in `tests/e2e`, standard pytest discovery rules in `tests/` do not automatically import it without configuration.
   - By placing `pytest_plugins = ["tests.e2e.conftest"]` at the head of each new test file in `tests/`, all 4 new test suites directly access `qapp_offscreen`, `isolated_controller`, `isolated_db`, `isolated_config`, and `offscreen_widgets` without modifying `pytest.ini` or `tests/conftest.py`.

2. **Opaque-Box Testing Strategy (Zero Source Modifications)**:
   - Test suites must be requirement-driven and opaque-box (testing contracts, signals, dimensions, properties, and outputs).
   - To guarantee tests execute cleanly against both current code and refactored code without false negatives:
     - Use helper inspection functions with duck-typing (`getattr`, `hasattr`).
     - Test properties and fallback methods gracefully (e.g. `getattr(ctrl, "_capture_state", ctrl._meeting_state)`).
     - Test UI dimensions, flags, and signals using deterministic Qt test methods (`QTest`, `qapp_offscreen.processEvents()`).

3. **Tier Distribution Compliance (TEST_INFRA.md & SCOPE.md)**:
   - Every feature must have >=5 Tier 1 isolated tests.
   - Every feature must have >=5 Tier 2 boundary tests.
   - All feature suites must include pairwise Tier 3 combination tests.
   - All feature suites must include realistic multi-step Tier 4 real-world user scenarios.
